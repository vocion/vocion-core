# Self-hosted fonts

Every face the app draws text in is served from this directory, so neither a
build nor a page ever fetches a font from Google. The files and
`src/styles/fonts.css` are generated by `scripts/fonts/self-host.mjs`: run it
(from `packages/core`) when a face is added or changed, and commit what it
writes.

Each family is licensed under the **SIL Open Font License, Version 1.1**. Its
full licence text, with its copyright notice, is the `OFL.txt` in its folder.
The fonts are unmodified, subset by Google Fonts as served.

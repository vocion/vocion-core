# Draft for Approval

Given one pending item and its context, produce the artifact a person can
approve, reject, or edit in a single pass — never the action itself.

Return:

1. **What is being approved**: the item, the audience, and the outcome sought.
2. **The draft**: the full artifact text, ready to use as written.
3. **Grounding**: the records the draft relies on, cited one per claim.
4. **Assumptions**: anything you had to assume, listed so it can be corrected.
5. **Open questions**: what must be confirmed before this is sent or applied.
6. **If rejected**: the next-best option, in one line.

Keep the draft in the voice the surrounding context establishes; do not invent
commitments, dates, prices, or names that the context does not contain. If a
required fact is missing, leave a marked placeholder and list it under open
questions rather than filling it in.

Nothing here is an action taken. This is a DRAFT for human approval.

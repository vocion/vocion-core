# Contractor Reconciliation

The source of record for hours is the time system the workspace connects;
the source of record for pay is the ledger (bills and payments to each
contractor). Name both before you start, and the period.

1. **Pay.** Each contractor's bills and payments in the period, from the
   ledger.
2. **Hours.** Each contractor's logged hours in the same period, by project,
   with the rate the time system holds.
3. **Match** on the contractor, then compare: hours times rate against what
   was billed.

Four buckets, as the reconcile skill says: matched, paid without hours,
hours without pay, and matched but different. For the last, show both
figures and the difference, and the project the hours were logged to.

A difference is a finding for a person, not a correction. Propose an entry
only when the cause is a coding error you can show (a bill coded to the
wrong project or account), never to make the totals agree.

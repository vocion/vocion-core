The factory's own record, kept where it does not compete with the things a
person manages. Every worker run is here: what it was, what phase it reached,
what it said it did, the tokens and the money it spent, and the pull request
it opened. Nothing is deleted; it is simply no longer in the way.

The other half of this section is [Releases](/dashboard/p/releases), every
deploy that reached people, with the announcement line the public reads and
the post-deploy health check. It has no nav row of its own and is reached from
here and from [Products](/dashboard/p/products).

A single run read whole is on the core stream at
[/dashboard/activity](/dashboard/activity).

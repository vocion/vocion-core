The four numbers on top are the answer. The sections under them say whether
the work was any good and what autonomy is actually saving. The table is the
evidence: every request sits under exactly one outcome, so the group totals
add up to the figures above.

Approvals a person accepted unchanged are the first candidates for raising an
agent's autonomy, because every one of those is a decision the system could have
made itself.

Run-level cost, cost by model and cost by agent are on
[Activity](/dashboard/p/activity), beside the run that spent them. What is in
flight and what it is waiting on is on [Work](/dashboard/p/work).

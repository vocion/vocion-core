# Writing a page brief

A writer should be able to write the page from the brief without asking a
question. Write it as one markdown artifact (folder `seo/briefs`) and attach
it with `seo_save_brief`.

## Read first

The client's project (rules first, then notes and three-star guidelines), the
page's SERP brief (its synthesis: intent, common subtopics, gaps, each cited
to page positions), and every feedback note already on this batch.

## The brief

1. **Query and intent**: the target keyword, the secondary keywords, and the
   one question the page answers.
2. **The angle**: what this page does that the top results do not (from the
   SERP brief's gaps, citing their positions), in one sentence.
3. **Outline**: the H1 and every H2 and H3, each with one line on what it
   says. The answer to the query comes first.
4. **Must include**: the brief's common subtopics, People Also Ask questions
   to answer, facts with their sources. Search volume only if
   `keyword_metrics` established it; otherwise leave it out.
5. **Client rules that apply**: quoted from the project, so the writer and
   the editor check the same lines.
6. **Internal links**: pages from the client's content inventory, with URLs.
7. **Meta**: title (under 60 characters) and description (under 155), and the
   URL slug.
8. **Length and format**: from the SERP brief's bar, plus schema or FAQ when
   the top results use them.

## Never

A statistic with no source, a competitor claim not in the SERP brief, or a
promise the client's rules forbid.

Fixes PLAT-3350. Bulk import ran one transaction for the whole file and
timed out over roughly 10,000 rows.

Now chunks the file into batches of 500 rows, each in its own
transaction, with a per-batch failure report returned to the caller
instead of a single failure for the file.

Behaviour change worth documenting: a partially successful import is now
possible, and the response includes `failed_rows`.

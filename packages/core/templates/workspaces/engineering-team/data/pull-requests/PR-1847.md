Adds a non-null `org_id` to `audit_entry` and backfills it from the
parent record.

The migration adds the column with a default, backfills in a single
`UPDATE`, then drops the default and sets `NOT NULL`.

Reviewer question: the table has 41 million rows in production. The
single-statement backfill was tested on a 2-million-row copy and took
19 seconds. There is no batching and no `CONCURRENTLY`.

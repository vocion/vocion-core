Fixes PLAT-3312. The scheduler stored the next run time in local time
and recomputed it in UTC, losing an hour at each transition.

Stores the next run time in UTC and converts for display only. Adds two
tests covering a spring-forward and a fall-back boundary in a zone that
observes them.

Does not migrate rows already holding a bad next-run time; those correct
themselves on the following run.

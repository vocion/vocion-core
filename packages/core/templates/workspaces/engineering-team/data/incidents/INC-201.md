## Symptom

Jobs scheduled between 02:00 and 03:00 local time did not run on
2026-08-30 for accounts in zones that observed a transition.

## Impact

31 accounts, one missed run each. No customer-facing outage. Re-saving
the schedule restored the next run.

## Timeline

- 07:04Z — first customer report.
- 08:20Z — reproduced; matched known defect PLAT-3312.
- 09:00Z — affected schedules re-saved by hand.
- 13:40Z — closed with a fix pending in PR-1852.

## Follow-up

PR-1852 stores the next run time in UTC. The postmortem action to alert
on a missed scheduled run is still open.

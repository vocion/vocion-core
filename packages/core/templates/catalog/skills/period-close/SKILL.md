# Period Close

The calendar is authored. Run it, and report against it.

Order by dependency, not by team. A task whose inputs are not ready is not
late, it is blocked, and the two need different responses.

Report daily: what completed, what is in progress, what is blocked and on
whom, and whether the close date is still achievable. Say the date is at
risk on the day it becomes at risk.

Track what recurs. The same task blocking every period is a process
problem, and naming it is worth more than working around it a fourth time.

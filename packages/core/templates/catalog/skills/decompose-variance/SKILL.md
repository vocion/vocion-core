# Decompose Variance

A variance is not a number, it is an explanation. Report the number, then
answer what moved it.

1. State the actual, the baseline, the gap in absolute and percentage terms.
2. Decompose into drivers that sum to the gap. Show the arithmetic.
3. Rank drivers by contribution — the top two or three usually carry most
   of it, and the rest is noise that should be named as noise.
4. For each material driver, one sentence on why, grounded in something
   you can point at.

Compare like with like. A part-period against a full period always looks
like a collapse — either match the windows or label the partial one
loudly. Say which baseline you used; "down 12%" means nothing until the
reader knows what against.

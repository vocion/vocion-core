# Generalize

For every part of a captured procedure, decide which it is:

- **Fixed** — the sequence, the sources, the output shape, the rules. This
  becomes the skill.
- **Varies** — dates, names, amounts, which record, which period. These
  become parameters.
- **Judgement** — where a person decides. These become gates.

A procedure that hardcodes the example only works on the example. Test
every constant by asking whether it would be the same next month, for a
different record, for a different person.

Corrections made during the capture usually mark judgement. "No, not that
one, we skip anything under the threshold" is a rule. "Hmm, depends" is a
gate.

Do not gate everything. Nine approvals is worse than doing it by hand.

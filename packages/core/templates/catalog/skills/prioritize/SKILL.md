# Prioritize

The model is authored. Apply it consistently, including to work somebody
senior wants.

Per item: the score by criterion, the total, and the evidence behind each
input. An estimate with no basis gets marked as a guess, because a guess
multiplied by a confident weight is still a guess.

**Show what falls below the line and what that costs.** Prioritisation is
the decision not to do things, and a list that only shows the top is not a
prioritisation.

Flag where the model produces an answer that feels wrong. That is either a
real insight or a flaw in the model, and both are worth surfacing rather
than quietly overriding.

# Deflect

Search the documentation and resolved history before opening anything.

Where the answer exists, **give the answer** and link the source. A bare
link reads as a brush-off; the answer plus the link reads as help and
teaches where to look next time.

Where the existing material is wrong, outdated or hard to find, say so and
flag it for updating. The third person to ask the same question is
evidence about the documentation, not about the person.

Never deflect something that only looks routine. If the detail suggests a
different underlying problem, route it properly.

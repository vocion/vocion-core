# Document From Evidence

Use their template. Matching the format they already use matters more than
improving it — a familiar document gets sent, a better unfamiliar one gets
rebuilt by hand.

**Every number comes from a comparable you can cite.** Past work, a rate
card, a prior document, a record. Never generate a figure to fill a slot.
Where there is no comparable, leave the line as a placeholder, say plainly
that it needs a number, and build the rest around it.

Every document states what is **not** included. Scope disputes start with
what nobody wrote down, and the exclusions section is the cheapest
insurance available.

Name the gaps out loud before presenting. Assumptions that would change the
document materially if wrong go in a list for the author — separate from
the document itself, never inside it.

# Route for Approval

Check before routing: correct parties named and correctly spelled, all
referenced attachments present, blanks filled, the version being routed is
the version agreed, and signature blocks matching the actual signatories.

Errors found after routing cost a full cycle and some credibility.

Route in the authored order. Where sequence matters, sequence it; parallel
routing of something needing internal approval first is how unapproved
terms get signed.

**State plainly what route is available** before asking for approval to
send. If the connected path cannot take this document, say so up front and
hand back the file — that is a complete outcome, not a failure.

Verify completion and record where the executed copy lives.

# Daily Digest

Scan the window across everything connected, then organise by topic or
project — never by source. People care what happened, not where it was
stored.

Lead with **action items**: direct requests, assignments, questions
awaiting a reply, review requests. Each carries who asked, where, and when.

Then decisions reached, then mentions, then updates on things being waited
on. Deduplicate across sources — one decision discussed in chat and
confirmed by mail is one entry with two citations.

If a source could not be reached, say which and carry on. Never let one
failure block the digest. Close with a one-line count so the scope of the
scan is visible.

# Component Doc

Open with what it is for in one sentence, and **when to use something
else**. That line prevents more misuse than the rest of the document
together.

Then: variants with the decision rule for choosing between them, every
state, the props with types and defaults, and the composition rules — what
it may contain and what it may sit inside.

Accessibility notes as obligations on the consumer: what must be provided,
what is handled for them, what breaks if it is overridden.

Include a do and a do-not with real examples. Abstract guidance gets
interpreted; examples do not.

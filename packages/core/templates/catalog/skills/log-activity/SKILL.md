# Log Activity

Resolve the records first — the organisation, the related item, the people
involved. Where more than one plausible parent exists, **ask**. Never guess
which one a conversation belonged to.

Draft the entry: a short scannable subject, the medium, the date it
actually happened, and three to six bullets covering what was discussed,
what was agreed, and what each side committed to.

Log it as **completed** and dated when it occurred. This is a record of
past work, not a task.

Show it exactly as it will be saved, then save it, then re-read to confirm
it attached where intended. Where writing is unavailable, hand back
paste-ready text — that is a complete outcome.

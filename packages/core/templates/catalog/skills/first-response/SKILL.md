# First Response

Acknowledge the specific thing, not the fact of contact. "Thanks for
getting in touch" says nothing; naming what is broken and what it is
blocking shows it was read.

Set an expectation you will meet. A specific date that holds beats a
shorter one that slips — the second response is where trust is actually
won or lost.

Give the workaround if one exists, even a poor one. Something that
unblocks somebody today is worth more than a better fix next week.

Never speculate about cause in a first response. "We are investigating" is
honest; a guess that turns out wrong has to be retracted in public.

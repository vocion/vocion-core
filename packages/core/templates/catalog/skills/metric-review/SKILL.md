# Metric Review

Lead with the metrics that matter against their targets, with the trend.
Everything else is context.

For anything materially off target, decompose it before explaining it.
"Signups are down" is a starting point; which segment, which source, since
when is the finding.

Distinguish a real change from noise. A metric inside its normal variation
is not a story, and treating it as one wastes the room's attention.

**End in a recommendation.** A review that reports numbers without a
proposed action is a dashboard read aloud. Say what to do, what it would
cost, and what you expect it to move.

# Doc Set

Document what the code does, not what it was intended to do. Where they
differ, that is the most valuable thing to record.

- **README** — what this is, how to run it, how to test it, and where to
  look for the rest. Somebody new must get it running from this alone.
- **Reference** — the interface, with types, errors and at least one real
  example per operation. Examples that can be copied and run.
- **Runbook** — how to operate it: what breaks, the symptoms, the response.

Say when each was last verified against the code. Documentation nobody
trusts is worse than none, because it is read before being distrusted.

# Render

Numbers lead, words follow. Not "sales were strong" — the figure, its
comparison, and the period.

**Every figure carries its baseline.** A number with nothing to compare it
to is a missed insight.

Name the outlier. "One region is down 22%, the only one below last year"
beats "results were mixed". The whole value of a report is finding the
thing worth looking at.

Three findings at most in the summary. The detail belongs in the appendix,
and the raw pull belongs behind that so somebody can check the arithmetic.

Right-align figures and use tabular digits so columns can be scanned. Mark
any figure that is partial, estimated or unavailable, and never substitute
a plausible number for a missing one.

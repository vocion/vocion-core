# Objection Response

State the concern as they would state it, at full strength. Answering a
weakened version is transparent and makes it worse.

Answer with evidence that can be checked. Where the concern is valid,
**say so** — conceding a true limitation buys the credibility that makes
the rest believable.

Distinguish concerns you can resolve, ones you can mitigate, and ones you
simply accept. Treating all three the same way is what makes responses
sound evasive.

Never disparage an alternative. Compare on what is demonstrable, and where
the alternative is genuinely better for their case, say that too.

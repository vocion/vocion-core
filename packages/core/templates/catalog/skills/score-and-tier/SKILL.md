# Score and Tier

Weights and criteria are authored. Apply them; do not improvise them.

For each record: start from the base score, apply each adjustment with its
evidence, and show the running arithmetic so the number can be argued with.
A score whose derivation is invisible gets ignored.

Respect the floor and the ceiling. A score that saturates tells you the
weights need revisiting, not that the record is certain.

Evidence for every adjustment must be specific — "no activity in 21 days,
last touch 4 March" not "engagement seems low". An adjustment you cannot
evidence does not get applied.

Group into tiers and say what each tier obliges somebody to do. A ranking
nobody acts on differently is a list, not a tiering.

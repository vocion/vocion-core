# Source Registry

Maintain the picture of what can actually be searched: which sources are
connected, which are reachable right now, and which are rate limited or
failing.

Priority order depends on the question. Decisions live in conversations;
status lives in trackers; policy lives in documentation. State the order
used so the ranking can be argued with.

**Always report coverage with the answer.** Which sources were searched,
which were skipped, and which failed. An answer drawn from two of six
connected systems is a partial answer and must say so.

Where nothing relevant is connected, say that plainly and name what would
need connecting — by category, never by vendor.

# Route

Route from the authored table on category and complexity. State which rule
applied and why.

Include what has already been checked or ruled out. The most common waste
in a queue is the next person repeating the first person's investigation.

**Never route into something that will half-work.** If the destination
lacks access, context or capacity, say that instead of routing and letting
it bounce back a day later.

Where nothing in the table fits, route to the default owner and flag it as
unmatched. An accumulation of unmatched items is how the table learns it
needs a new row.

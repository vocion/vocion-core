# Redline

Propose actual text, not a description of the concern. "Consider limiting
liability" is not a redline; the clause as you want it to read is.

Per change: the current text, the proposed text, one line on why, and the
**fallback** — what is acceptable if they refuse, taken from the authored
positions.

Mark each as required or preferred. A redline that treats every change as
essential gets negotiated as a whole rather than clause by clause, which
costs the important ones.

Where a change is outside the authored positions, say so and escalate
rather than inventing a position.

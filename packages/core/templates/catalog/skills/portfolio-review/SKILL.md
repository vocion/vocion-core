# Portfolio Review

Three sections, and the third is the one that earns its keep:

1. **Where things stand** — totals by stage or category, against target
   where one exists.
2. **What moved** — entered, advanced, regressed, closed since the last
   run. Show the net, not just the gross.
3. **What changed that nobody logged** — records whose evidence has moved
   while the record has not. A conversation that happened with no activity
   recorded; a state that no longer matches what exists.

Name the biggest single mover in each direction. An average hides the two
records that explain the quarter.

Where the previous run is unavailable, say so and report position only.

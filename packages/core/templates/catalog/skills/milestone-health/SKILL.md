# Milestone Health

A colour without evidence is a feeling. Every status names what it is based
on: work completed against plan, dependency state, and known risks.

Use the org's authored thresholds. Where none exist, state the rule you
applied so it can be argued with.

**Amber must mean something.** If everything is amber, the scale is being
used to avoid a conversation. Red means the date moves unless something
changes, and saying so early is the entire job.

For anything not green: what would return it to green, who can do that, and
by when. A status report without that line is an observation, not
management.

# Creative Performance

A creative comparison is only worth reading if the comparison was fair.
Check before reporting:

- **Exposure.** Did each asset get a comparable chance? An asset that ran
  for a day against one that ran for a month is not a result.
- **Volume.** Is there enough of it to mean anything? Say the number the
  rate is computed on, every time. A 12% rate on 25 events is noise wearing
  a percentage sign.
- **Confounds.** Different audiences, placements, or periods make the
  creative comparison unreadable. Name them rather than reporting through
  them.

Report the metric that matters downstream, not the one that moves most. A
high engagement rate on an asset that converts nothing is a finding about
the metric.

**Name the losers.** The value here is knowing what to stop, and a report
that only ranks winners leaves the spend where it is.

Where the comparison cannot be made fairly, say so and say what would fix
it — usually a rerun with equal exposure.

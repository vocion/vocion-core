# Vendor File

One view per counterparty across every connected system: what agreements
exist, what each covers, when each was signed, and when each ends.

**Name the gaps explicitly.** An expected agreement that does not exist is
the finding, and it is invisible in any view that only lists what was
found.

Flag by date: what expires, what auto-renews and by when notice must be
given, and what has already lapsed while the relationship continued.

Note where different agreements with the same counterparty conflict.
Layered amendments over years are where that lives, and nobody notices
until it matters.

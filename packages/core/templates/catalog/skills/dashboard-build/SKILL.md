# Dashboard Build

Lead with the two or three figures that would change a decision. Everything
else is supporting detail and goes below.

One question per view. A chart answering two questions answers neither, and
the fix is two charts.

Encode state in form as well as colour — a status needs a label or a shape,
not only a hue, or it disappears for a meaningful fraction of readers.

Ship the raw pull on a final tab. The first thing a numerate reader does is
try to reproduce a figure, and a dashboard that makes that impossible does
not get trusted twice.

Say when it was generated and what period it covers, on the artifact
itself.

# RAID Register

Four categories, kept distinct because they need different responses:

- **Risk** — might happen. Carries likelihood, impact, and a mitigation.
- **Assumption** — being treated as true without proof. Carries what
  happens if it is false, and how it could be checked.
- **Issue** — already happening. Carries an owner and a resolution date.
- **Dependency** — needed from elsewhere. Carries who, and by when.

Every entry has one named owner. "The team" owns nothing.

Review by exception: what changed, what is newly overdue, what can be
closed. A register that only grows is not being used.

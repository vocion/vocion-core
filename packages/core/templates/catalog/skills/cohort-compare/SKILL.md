# Cohort Compare

Define the cohorts and the axis before pulling. Comparing everything to
everything produces a table nobody reads.

Cohorts must be defined identically across periods. A definition that
drifts between periods produces a trend that is an artifact of the
definition.

Show absolute and relative together. A 50% rise on a base of four is not
the same story as a 50% rise on a base of four thousand, and showing only
the percentage hides which one it is.

Report cohort sizes alongside the metric. A cohort too small to be
meaningful gets reported with the number and the caveat, never dropped
silently.

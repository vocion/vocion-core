# Author Entry

Write it in **their vocabulary**, not in generic business language. A
definition full of unfamiliar terms is one nobody trusts to run unattended.

The manifest carries: slug and name, a description saying what it is for,
the system prompt, the skills it composes, and what it reaches for by
connector **category** — never by vendor.

Compose from existing skills wherever one fits. A new skill that duplicates
an existing one under a different name is the defect this is meant to
prevent; where the existing one nearly fits, lift its standard out as a
parameter rather than forking it.

Every definition works with nothing connected. State what it does from
uploaded material, because that is the path most first runs take.

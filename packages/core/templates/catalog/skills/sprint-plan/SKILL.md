# Sprint Plan

Carryover first. Work that did not finish last time is already spent
capacity, and a plan that ignores it starts over-committed.

Then: capacity from the capacity-fit pass, backlog sized, and a clear line
between **committed** and **stretch**. Committed should fit inside capacity
with room; stretch is what gets picked up if it goes well. Blurring the two
makes the commitment meaningless.

State the sprint goal in one sentence. If the selected work does not add up
to a goal somebody could state, the selection is a list of tickets rather
than a plan.

Name what was deliberately not selected and why — that list is the
prioritisation, made visible.

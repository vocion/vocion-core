# Stage Evidence Check

Each state has authored exit criteria. Check them against what exists, not
against what the record claims.

Three verdicts, and each is useful:
- **Matches evidence** — the criteria are met and demonstrable.
- **Ahead of evidence** — the state claims progress nothing supports. The
  common case, and the one that corrupts every forecast built on it.
- **Behind evidence** — the work is further along than the record says.

Cite the specific artifact for each criterion: the document that exists,
the conversation where it was agreed, the field that is populated. "Seems
fine" is not evidence.

Recommend the state the evidence supports, and leave the change to
propose-update.

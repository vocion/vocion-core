# Frame Problem

Write the problem without naming a solution. If the statement contains the
answer, the framing has already closed the option space.

- **Who has it** — specifically, and how many.
- **What they do today** — the workaround, which is evidence the problem is
  real and a measure of how much it costs them.
- **The evidence** — research, tickets, data, with sources. Say how strong
  it is.
- **What success looks like** — a number that would move, with a baseline.
- **Why now** — what changed. If nothing changed, that is worth knowing.

State what would tell you this is not worth solving. A framing that cannot
be disconfirmed is advocacy.

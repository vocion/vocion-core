# Comp Band

State the benchmark source, its date and its comparator set before any
number. A benchmark from a different market or a different year is a
different number.

Place against the authored bands with the reasoning. Report where somebody
sits in their band and how they got there.

**Surface outliers in both directions.** Below-band creates retention risk;
above-band creates a problem at the next cycle, and both need deciding
rather than discovering.

Flag compression — where a new hire approaches or exceeds an existing
person at the same level. It is the most common cause of avoidable
departures and is visible in the data before it is visible in behaviour.

Handle this data at the sensitivity it carries.

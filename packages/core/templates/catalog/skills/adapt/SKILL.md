# Adapt

Hold the substance constant and change the frame. If the facts change
between versions, that is not adaptation.

Per channel: length, structure and formality. What works as a three-
paragraph email becomes two sentences in chat and a different shape again
as a formal notice.

Per audience: what they need and what they can be assumed to know. An
executive version is shorter and leads with the decision; a technical
version keeps the mechanism.

**Check every version for contradiction** before handing them over. Two
versions of one message that disagree in the same thread is the failure
mode this exists to avoid.

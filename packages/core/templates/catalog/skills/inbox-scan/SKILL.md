# Inbox Scan

Two piles, and the split is the whole value:

**Waiting on you** — a question directed at the author, a review request,
an approval, a thread that stopped because they did not reply. Sort by how
long it has been waiting, oldest first, because that is the one about to
become a problem.

**Waiting on them** — the author asked and has not heard back. Same sort.
This is the pile nobody tracks and the one where things quietly die.

Everything else is noise and does not appear. A scan that lists the whole
inbox has not done its job.

For each item: who, what is needed, how long it has waited, and the single
next move.

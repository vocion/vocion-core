# Commitment Capture

Scan for commitments in both directions: things the author promised, and
things somebody promised them.

A commitment has an owner, an object, and ideally a date. "I'll send that
over" is a commitment with a missing date — capture it and flag the gap
rather than inventing Friday.

Quote the sentence it came from, so the person can see why you think it is
a commitment.

**Always offer, never auto-add.** Present the list and let somebody choose.
A task list that grows on its own stops being trusted, and an untrusted
task list is worse than none.

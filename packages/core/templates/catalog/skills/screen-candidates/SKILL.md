# Screen Candidates

The rubric is authored and applied identically to every application. An
inconsistently applied rubric is worse than none, because it produces
defensible-looking output from an indefensible process.

Per candidate, per dimension: the evidence from the application, and the
rating. **Absent evidence is recorded as absent**, never inferred from
something adjacent.

Rank, then state the shortlist and the line. Say what separates the last
candidate above from the first below — that comparison is where an unstated
bias becomes visible.

Flag where the rubric could not be applied for lack of information, and say
what to ask. Rejecting for a gap the form never asked about is a process
fault.

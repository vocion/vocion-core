# Weekly Digest

Same shape as the daily digest, different editorial rule: **significance
over completeness.** A week contains too much to list. Choose.

Lead with what changed in the world rather than what happened in the tools:
decisions made, things that shipped, things that slipped, people who joined
or left a thread that matters.

For each project touched, one short paragraph: where it was, where it is,
what is next. Not a list of events.

Name what went quiet. A project with no activity for a week is information,
and it is the thing a weekly digest can see that a daily one cannot.

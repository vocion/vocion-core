  How what a {{company}} customer said becomes a request the factory can rank —

A signal becomes a request when the same need comes up more than once. File
it with:

1. **The need, in one line**, in the customer's terms — what they are trying
   to do, not the feature they named.
2. **Their words, quoted**, with who said it and where (the thread, the review,
   the call), for each customer who raised it.
3. **How many** said the same, and since when.

Search first: if a request for this need exists, add the new quotes to it
instead of filing another. Never promise a customer the feature or a date, and
never rank the request — the product manager does.
